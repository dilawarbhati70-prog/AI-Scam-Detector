# 🛡️ AI Scam & Phishing Detector

An AI-powered web application that analyzes suspicious SMS, emails, and messages for possible scams and phishing attempts.

## Features

- 🤖 AI-powered scam analysis
- 🚩 Warning-sign detection
- 🔗 URL analysis
- 🏷️ Scam category detection
- 📊 Risk score
- 🕘 Analysis history
- 🇵🇰 English and Urdu analysis
- 🔐 Secure API-key handling

## Technologies

- Python
- Streamlit
- Google Gemini API

## Security

API keys are stored using Streamlit secrets and are not included in the source code.

## Disclaimer

This application provides AI-assisted analysis and does not guarantee that a message is safe or malicious.
